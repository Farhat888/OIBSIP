# Retail Sales Data – Exploratory Data Analysis

## 1. Project Overview
This project focuses on performing Exploratory Data Analysis (EDA) on a retail sales dataset to identify sales patterns, customer behaviour trends, and actionable business insights.

## 2. Objectives
- Understand the structure and quality of the dataset.
- Analyse sales trends over time.
- Explore customer demographics.
- Identify top-selling products and revenue by category.
- Examine relationships between numerical variables.
- Develop actionable business recommendations.

## 3. Tools & Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## 4. Project Workflow
1. Data Loading and Initial Inspection
2. Data Quality Checks

4. Time Series Analysis
5. Customer Demographics Analysis
6. Product and Revenue Analysis
7. Correlation Analysis
8. Additional Visualisation
9. Business Insights and Recommendations
